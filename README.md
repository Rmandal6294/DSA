## 📖 About

This repository documents my complete learning journey through Data Structures and Algorithms, from basic concepts to advanced problem-solving techniques. Each section includes theory, implementations, and practice problems with detailed explanations.

## 🎯 Goals

- Master fundamental data structures and algorithms
- Develop strong problem-solving skills
- Build a comprehensive reference for interview preparation
- Track progress and maintain consistency
- Share knowledge with the community

## 📚 Content Structure

### **Phase 1: Foundations**
- [ ] **Arrays & Strings**
  - Basic operations
  - Two-pointer technique

### **Phase 2: Linear Data Structures**
- [ ] **Linked Lists**
  - Singly linked list
  - Doubly linked list
  - Circular linked list
  - Common patterns

- [ ] **Stacks & Queues**
  - Implementation using arrays/linked lists
  - Applications
  - Monotonic stack/queue
  - Deque

- [ ] **Hashing**
  - Hash functions
  - Collision resolution
  - Hash maps and sets
  - Applications

### **Phase 3: Non-Linear Data Structures**
- [ ] **Trees**
  - Binary trees
  - Binary search trees
  - AVL trees
  - Tree traversals (Inorder, Preorder, Postorder, Level-order)
  - N-ary trees

- [ ] **Heaps**
  - Min heap & Max heap
  - Priority queue
  - Heap sort
  - Applications

- [ ] **Graphs**
  - Representations (Adjacency matrix, Adjacency list)
  - BFS & DFS
  - Shortest path algorithms
  - Minimum spanning tree
  - Topological sorting

- [ ] **Advanced Trees**
  - Segment tree
  - Fenwick tree (BIT)
  - Trie
  - Suffix array/tree

### **Phase 4: Algorithmic Paradigms**
- [ ] **Searching & Sorting**
  - Linear & Binary search
  - Bubble, Selection, Insertion sort
  - Merge sort, Quick sort
  - Counting, Radix, Bucket sort

- [ ] **Recursion & Backtracking**
  - Recursion fundamentals
  - Backtracking patterns
  - N-Queens, Sudoku solver
  - Subset generation

- [ ] **Greedy Algorithms**
  - Greedy choice property
  - Activity selection
  - Huffman coding
  - Job sequencing

- [ ] **Divide & Conquer**
  - Binary search variants
  - Merge sort, Quick sort
  - Closest pair of points
  - Strassen's matrix multiplication

- [ ] **Dynamic Programming**
  - Memoization vs Tabulation
  - 1D DP
  - 2D DP
  - DP on trees/graphs
  - DP optimization techniques

### **Phase 5: Advanced Topics**
- [ ] **String Algorithms**
  - Pattern matching (KMP, Rabin-Karp)
  - Z-algorithm
  - Manacher's algorithm
  - String hashing

- [ ] **Bit Manipulation**
  - Bitwise operators
  - Common bit tricks
  - Applications

- [ ] **Advanced Graph Algorithms**
  - Strongly connected components
  - Bridges and articulation points
  - Network flow
  - Bipartite matching

- [ ] **Mathematical Algorithms**
  - Fast exponentiation
  - Sieve of Eratosthenes
  - Extended Euclidean algorithm
  - Matrix exponentiation
